
# Проект для лабораторной работы 7

Этот репозиторий создан в рамках **лабораторной работы №7** по изучению системы контроля версий Git и платформы GitHub.

1. Демонстрация работы с Git
2. Изучение возможностей GitHub
3. Практика совместной разработки
